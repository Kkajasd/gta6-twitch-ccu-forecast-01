Forecasts GTA VI's launch-day Twitch viewers hour by hour (hours 2–24) from the first hour's concurrent viewers, using per-hour log-log regression calibrated on past console launch curves. Leave-one-out pinball loss 0.155 on the console stratum, against 0.344 for the flat baseline.
